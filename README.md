# Bank Loan Analysis

## Overview
The **Bank Loan Analysis** project is designed to provide insights into loan data, helping financial institutions evaluate loan applications, predict default risks, and identify patterns in customer behavior. This project leverages data analysis and machine learning techniques to deliver actionable insights.

### Key Objectives:
- Analyze loan data to understand trends and customer behavior.
- Predict loan defaults using machine learning models.
- Provide visualizations to communicate insights effectively.

---

## Features
- **Exploratory Data Analysis (EDA):**
  - Summary statistics and data cleaning.
  - Detection of outliers and missing values.
- **Data Analysis Expression(DAX):**
  - Mathematical calculations to find values & visualize data
  - Data Analysis Expresssion evaluation and comparison.
- **Data Visualization:**
  - Interactive dashboards and charts.
  - Correlation heatmaps and loan trend graphs.
- **Reporting:**
  - Generate comprehensive reports for stakeholders.
